# Md Jahidul Islam — Portfolio

A simple, modern one-page portfolio site. Pure HTML/CSS/JS, no build step required.

## Files

- `index.html` — page content
- `style.css` — styles
- `script.js` — mobile nav toggle + footer year
- `assets/profile.jpg` — your photo

## How to host on GitHub Pages

1. Create a new GitHub repository. For a **user site** (URL like `https://jahidul68.github.io`), name it exactly `jahidul68.github.io`. For a **project site** (URL like `https://jahidul68.github.io/portfolio`), name it anything, e.g. `portfolio`.
2. Upload all the files in this folder (`index.html`, `style.css`, `script.js`, and the `assets` folder) to the repository, keeping the same folder structure.
3. On GitHub, go to the repo's **Settings → Pages**.
4. Under "Build and deployment", set **Source** to `Deploy from a branch`, pick the `main` branch and `/ (root)` folder, then **Save**.
5. Wait a minute or two — GitHub will publish the site and show you the live URL at the top of the Pages settings page.

## Customizing later

- Update text directly in `index.html` (sections are clearly labeled: About, Education, Experience, Focus, Contact).
- Swap `assets/profile.jpg` for a new photo (keep a similar portrait aspect ratio for the best fit).
- Colors and spacing live at the top of `style.css` under the `:root` block if you want to tweak the theme.
